# Ключевые функции приложения «Домашняя библиотека»

1. Добавление новых книг в каталог с указанием автора, названия, жанра и года издания.
2. Поиск и фильтрация книг по автору, названию или статусу прочтения.
3. Отметка прогресса чтения и выставление персональных оценок книгам.
4. Учёт книг, временно переданных для чтения друзьям и знакомым.
