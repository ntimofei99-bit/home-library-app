# Домашняя библиотека (Home Library)
Консольное приложение на языке Python для учёта книг домашней библиотеки. Позволяет хранить информацию об авторах, названиях и статусе прочтения книг.

## Основные функции
* Добавление новой книги
* Поиск по автору или жанру
* Отметка о прочтении
* Удаление записи
